# Drop-in asset

`RM_MHA_to_ARKit.uasset` — the fitted RigMapper Definition, ready to use.

**Install:** copy it to `YourProject/Content/ARKitRemap/RM_MHA_to_ARKit.uasset`
(create the folder if needed), then restart or rescan. It has no external
dependencies, so it loads in any UE 5.8 project with the RigMapper plugin
enabled.

Prefer building from source? Create a RigMapper Definition asset and
right-click → Load From Json → [`../RM_MHA_to_ARKit.json`](../RM_MHA_to_ARKit.json)
— identical result.
